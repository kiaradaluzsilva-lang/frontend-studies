📚 Student Front-End

📖 Sobre o Repositório

Este repositório foi criado para reunir meus estudos e práticas de desenvolvimento Front-End ao longo da minha formação em Análise e Desenvolvimento de Sistemas.

Aqui serão armazenados exercícios, desafios, experimentos, anotações e pequenos projetos desenvolvidos durante o aprendizado de tecnologias voltadas para a construção de interfaces web.

O objetivo é registrar minha evolução, praticar conceitos fundamentais e acompanhar meu progresso como desenvolvedora.

---

🎯 Objetivos

- Praticar HTML5 e CSS3.
- Aprimorar conhecimentos em JavaScript.
- Explorar Bootstrap e outros frameworks.
- Desenvolver layouts responsivos.
- Aplicar boas práticas de organização e escrita de código.
- Registrar minha evolução como Desenvolvedora Front-End.
